# Stock · Innovation Space

เว็บนับสต๊อกของห้อง Innovation Space — ดูของที่ขาด/ใกล้หมด, เพิ่ม/แก้ไข/ลบรายการ, รับเข้า/เบิกออก, ตรวจนับ,
ตำแหน่งจัดเก็บพร้อมผังห้อง และจุด Live point ชี้ว่าของที่ค้นหาอยู่ตรงไหน ข้อมูลเก็บใน Google Sheet เดียวกับระบบอื่น

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (5 แท็บ: ภาพรวม, รายการทั้งหมด, ตรวจนับ, ผังห้อง & ตำแหน่ง, ประวัติ) |
| `Code.gs` | Apps Script backend (โปรเจกต์แยก) |
| `js/config.js` | **ตั้งค่าทั้งหมด**: `API_URL`, รูปผังห้อง, รายชื่อผู้ทำรายการ, หมวดหมู่ตั้งต้น |
| `js/api.js` · `app.js` · `views.js` · `plan.js` · `main.js` | โค้ดหน้าเว็บ |
| `css/stock.css` | สไตล์ |
| `plan.png` | **รูปผังห้อง** (ยังไม่มี — วางไฟล์นี้เมื่อได้ผังมา) |

## ติดตั้ง

1. script.google.com > New project > วาง `Code.gs` ทั้งไฟล์
2. ใส่ ID ของ Spreadsheet Group Management ที่ `STOCK_SPREADSHEET_ID`
3. Run `setupSheets()` 1 ครั้ง (สร้างแท็บ `Stock_Items`, `Stock_Locations`, `Stock_Log` + อนุญาตสิทธิ์)
4. Deploy > New deployment > Web app — Execute as: **Me**, Who has access: **Anyone**
5. คัดลอก URL `/exec` ไปใส่ `API_URL` ใน `js/config.js` แล้ว push
6. แก้ `Code.gs` ทีหลัง: Deploy > Manage deployments > Edit > **New version** (URL เดิม)

## ใช้งาน

- **ผู้ทำรายการ** (มุมขวาบน): เลือกชื่อก่อนเพิ่ม/แก้ไข/ลบ/นับ — รายชื่อมาจาก `Staff_Name` + `Volunteer_Name`
  เครื่องจะจำชื่อที่เลือกไว้ ทุกการเปลี่ยนแปลงถูกบันทึกในแท็บ `Stock_Log` พร้อมชื่อนี้
- **ของขาด**: "หมด" = คงเหลือ 0, "ใกล้หมด" = คงเหลือ ≤ จำนวนขั้นต่ำ (ตั้งขั้นต่ำ 0 = ไม่แจ้งเตือนใกล้หมด)
- **+ / −** ในตารางรายการ = รับเข้า/เบิกออกทีละ 1, ปุ่ม **รับ/เบิก** = ทีละหลายชิ้นพร้อมหมายเหตุ
  (คำนวณจากยอดใน Sheet ณ ตอนกด ถ้ามีหลายคนกดพร้อมกันยอดไม่ทับกัน)
- **ตรวจนับ**: กรอกจำนวนที่นับได้จริงทีละตำแหน่ง ช่องที่ว่างไว้ = ยังไม่ได้นับ (ไม่เปลี่ยนยอด)
- **ค้นหา** (ช่องบนสุด): พิมพ์ชื่อ/หมวด/ตำแหน่ง แล้วเลือก → เปิดผังพร้อมจุดแดงกระพริบที่ตำแหน่งของนั้น
- **ตำแหน่งจัดเก็บ**: เพิ่มตำแหน่ง แล้วกด 📌 แล้วคลิกบนผังเพื่อวางจุด (ย้ายจุดได้ด้วยวิธีเดียวกัน)
  ลบตำแหน่งได้เมื่อไม่มีของอยู่แล้วเท่านั้น

## ผังห้อง

วางรูปชื่อ `plan.png` ในโฟลเดอร์นี้ (หรือเปลี่ยนชื่อไฟล์ที่ `PLAN_IMAGE` ใน `js/config.js`)
ตำแหน่งจุดเก็บเป็น % ของความกว้าง/สูงของรูป — ถ้าเปลี่ยนรูปใหม่ที่ขอบเขตห้องเท่าเดิม จุดจะไม่เพี้ยน
ระหว่างที่ยังไม่มีรูป หน้าเว็บแสดงตารางกริดแทน วางจุดบนกริดไปก่อนได้

## แท็บใน Sheet

| แท็บ | คอลัมน์ |
|---|---|
| `Stock_Items` | id, name, category, unit, qty, minQty, locationId, locationNote, note, imageUrl, createdAt, updatedAt, updatedBy |
| `Stock_Locations` | id, name, zone, x, y, note |
| `Stock_Log` | timestamp, itemId, itemName, action, delta, qtyAfter, by, note |

แก้ข้อมูลในชีตตรงๆ ได้ แต่ห้ามแก้/ลบคอลัมน์ `id` และห้ามสลับลำดับหัวตาราง (เพิ่มคอลัมน์ใหม่ต่อท้ายได้)

> ⚠ ไม่มีระบบ login: ใครมี URL ของหน้าเว็บหรือ `/exec` ก็ดู/แก้สต๊อกได้ ทุกการแก้ไขมีชื่อผู้ทำรายการใน `Stock_Log`

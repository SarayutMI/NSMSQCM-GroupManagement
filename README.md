# ระบบจองห้องกิจกรรมโรงเรียน (School Group Management) — เวอร์ชันโครง

ปฏิทินจองห้อง Innovation Space / InspireLab / Other Activity ดีไซน์โทนน้ำเงิน-ขาว-เทา
เวอร์ชันนี้เป็น **โครงต้นแบบ (prototype)** ให้เห็นฟังก์ชันทั้งหมดครบก่อน โดย:

- **ข้อมูลการจอง** เก็บอยู่ใน localStorage ของเบราว์เซอร์ (ยังไม่ต้อง deploy อะไรเพิ่ม เปิดใช้ได้ทันที)
- **Google Sheet** ใช้เป็น **ข้อมูลอ้างอิง (Reference data)** เท่านั้น — คือรายชื่อโรงเรียน ที่จะโผล่เป็นตัวเลือกอัตโนมัติตอนกรอกฟอร์มจอง (พร้อมดึงชื่อผู้ประสานงาน/เบอร์โทรมาเติมให้อัตโนมัติถ้ามีในชีต)

ไฟล์ในชุดนี้:
- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — ดีไซน์/สีสัน/เลย์เอาต์ทั้งหมด
- `script.js` — โค้ดการทำงานทั้งหมด (ปฏิทิน, ฟอร์ม, เอกสาร ฯลฯ)
- `Code.gs` — โค้ด Backend (Google Apps Script) สำหรับเชื่อมข้อมูลการจองกับ Google Sheet จริง — ดูวิธีติดตั้งในหัวข้อ "เชื่อมข้อมูลการจองกับ Google Sheet จริง" ด้านล่าง
- `README.md` — คู่มือนี้

> **สำคัญ:** ทั้ง 4 ไฟล์ (`index.html`, `style.css`, `script.js`, `Code.gs`) ต้องอยู่ใน**โฟลเดอร์เดียวกัน** ห้ามแยกเก็บคนละที่ ไม่งั้นหน้าเว็บจะโหลดไม่สมบูรณ์ (ดีไซน์หายหรือกดอะไรไม่ได้)

## เปิดใช้งานทันที (ไม่ต้องตั้งค่าอะไร)

ดับเบิลคลิกเปิด `index.html` ได้เลย (ต้องต่อเน็ตครั้งแรกเพื่อโหลดฟอนต์และไลบรารีสร้างไฟล์ Word) ระบบจะขึ้นข้อมูลตัวอย่าง ให้ลองใช้ครบทุกฟังก์ชัน:
- ปฏิทินมุมมองเดือน / สัปดาห์ / วัน
- การจอง 1 ครั้งใส่ได้ **หลายกิจกรรม** (Innovation Space, Inspire Lab, อื่นๆ) พร้อมเรื่อง/หัวข้อ เวลา จำนวนรอบ และ **ราคาต่อคนต่อรอบ** — ระบบคำนวณ ราคา × จำนวนคน ให้อัตโนมัติทุกกิจกรรม พร้อมยอดรวมทั้งหมด
- เช็คเวลาจองซ้อนอัตโนมัติ (ห้องเดียวกัน + เวลาทับซ้อน)
- สถานะรอยืนยัน / ยืนยันแล้ว / ยกเลิก
- ค้นหาและกรองตามห้อง/สถานะ
- **ออกเอกสาร 2 แบบ ทั้ง PDF และ Word (.docx) จริง ด้วยฟอนต์ TH Sarabun PSK**:
  1. **แบบตอบรับการจองเข้าร่วมกิจกรรม** — ฟอร์มยืนยันพร้อมกาเครื่องหมายกิจกรรมที่จอง
  2. **ตารางการเข้าร่วมกิจกรรม + สรุปค่าใช้จ่าย** — ตารางตามช่วงเวลา พร้อมสรุปยอดเงินทุกกิจกรรมและยอดรวม

### ปรับแต่งข้อความในเอกสาร
เปิดไฟล์ `script.js` หาก้อน `DOC_CONFIG` ที่ด้านบนของไฟล์ แก้ชื่อสถานที่ อีเมล เบอร์ติดต่อ และเงื่อนไข/หมายเหตุต่างๆ ให้ตรงกับหน่วยงานจริงได้เลย

### เรื่องฟอนต์ TH Sarabun PSK
เอกสารทั้ง PDF (พิมพ์จากเบราว์เซอร์) และ Word ตั้งฟอนต์เป็น **TH Sarabun PSK** ไว้แล้ว:
- ไฟล์ **Word**: เปิดเครื่องไหนก็ได้ระบุฟอนต์นี้ไว้ในไฟล์ แต่จะแสดงผลสวยงามตรงแบบ ต้อง**ติดตั้งฟอนต์ TH Sarabun PSK** ในเครื่องที่เปิดไฟล์ (ฟอนต์มาตรฐานราชการไทย ดาวน์โหลดฟรีได้ทั่วไป) ถ้าไม่มีฟอนต์นี้ Word จะขึ้นแทนด้วยฟอนต์อื่นแทน
- ไฟล์ **PDF** (พิมพ์จากเบราว์เซอร์): ถ้าเครื่องที่เปิดเว็บมีฟอนต์ TH Sarabun PSK ติดตั้งอยู่ จะใช้ฟอนต์นั้นเลย ถ้าไม่มีจะโชว์ด้วยฟอนต์ Sarabun (Google Font) แทนโดยอัตโนมัติ ยังคงอ่านภาษาไทยได้ปกติ

## เชื่อมข้อมูลการจองกับ Google Sheet จริง (auto-create ให้อัตโนมัติ)

ค่าเริ่มต้นระบบเก็บข้อมูลการจองในเบราว์เซอร์เครื่องเดียว ถ้าต้องการให้หลายคนใช้งานพร้อมกันและเห็นข้อมูลตรงกันจริงบน Google Sheet ทำตามนี้:

1. สร้าง Google Sheet ใหม่ 1 ไฟล์ (ปล่อยว่างไว้ได้เลย **ไม่ต้องสร้างชีตย่อยหรือพิมพ์หัวตารางเอง**)
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างเดิมทั้งหมด แล้วคัดลอกเนื้อหาทั้งหมดจากไฟล์ `Code.gs` ที่แนบมาวางแทน กด บันทึก
4. มุมขวาบนกด **Deploy > New deployment** เลือกประเภท **Web app** ตั้งค่า:
   - **Execute as:** Me
   - **Who has access:** Anyone
   กด **Deploy** แล้วกด Authorize access ตามที่ระบบขอ
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. เปิดไฟล์ `script.js` หาบรรทัด `API_URL: ''` แล้ววาง URL ที่ได้ลงไป:
   ```js
   const CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxxxxxxxxxxxxxx/exec',
     ...
   };
   ```
7. บันทึกไฟล์ แล้วเปิดเว็บใหม่

**ไม่ต้องสร้างชีตหรือหัวตารางเอง** — พอมีการจองแรกเข้ามา (หรือแค่เปิดหน้าเว็บ) ระบบจะสร้างชีตชื่อ `Bookings` พร้อมหัวตารางที่ต้องใช้ให้อัตโนมัติในสเปรดชีตที่ผูกกับสคริปต์นั้นทันที แถบด้านซ้าย "ข้อมูลการจอง (Sheet)" จะแสดงสถานะการเชื่อมต่อให้เห็นชัดเจน

> ทุกครั้งที่แก้โค้ด `Code.gs` ต้องกด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** ใหม่ URL เดิมยังใช้ได้เหมือนเดิม

ถ้าไม่ได้ตั้งค่า `API_URL` ระบบจะกลับไปทำงานแบบ "โหมดทดลอง" เก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเครื่องเดียวเหมือนเดิม (เหมาะสำหรับลองใช้งานหน้าตาระบบก่อน)

## ขั้นตอน (ทางเลือก): เชื่อมรายชื่อโรงเรียนจาก Google Sheet จริง

ถ้าอยากให้ dropdown "ชื่อโรงเรียน" ดึงจากรายชื่อจริงของโรงเรียน (แทนข้อมูลตัวอย่าง) ทำตามนี้:

1. สร้าง Google Sheet ใหม่ ตั้งชื่อคอลัมน์แถวแรกเป็น:
   ```
   school, contactPerson, contactPhone
   ```
   แล้วกรอกรายชื่อโรงเรียนที่ต้องการ เช่น
   ```
   school,contactPerson,contactPhone
   โรงเรียนสาธิต...,ครูสมชาย,081-234-5678
   โรงเรียนวัดบวร...,ครูสมหญิง,089-999-8888
   ```
2. เมนู **ไฟล์ (File) > แชร์ (Share) > เผยแพร่ทางเว็บ (Publish to web)**
3. เลือกแท็บที่มีข้อมูล เลือกรูปแบบเป็น **ค่าที่คั่นด้วยจุลภาค (.csv)** แล้วกด **เผยแพร่**
4. คัดลอกลิงก์ที่ได้ (จะขึ้นต้นด้วย `https://docs.google.com/spreadsheets/d/.../pub?...`)
5. เปิดไฟล์ `script.js` ด้วยโปรแกรมแก้ไขข้อความ หาบรรทัด:
   ```js
   const CONFIG = {
     API_URL: '',
     SCHOOLS_CSV_URL: ''
   };
   ```
   แล้ววางลิงก์ลงใน `SCHOOLS_CSV_URL`:
   ```js
   SCHOOLS_CSV_URL: 'https://docs.google.com/spreadsheets/d/xxxxx/pub?output=csv'
   ```
6. บันทึกไฟล์ แล้วเปิดใหม่ — แถบด้านซ้าย "ข้อมูลอ้างอิง (Sheet)" จะแสดงว่าเชื่อมต่อสำเร็จ และช่องชื่อโรงเรียนในฟอร์มจะมีตัวเลือกจากชีตจริงให้พิมพ์ค้นหา

> การแก้ไขรายชื่อโรงเรียนในชีตในภายหลัง จะอัปเดตในหน้าเว็บอัตโนมัติเมื่อกดปุ่ม "⟳ ซิงก์ข้อมูลอ้างอิง" หรือรีเฟรชหน้า (Google ใช้เวลาสักครู่ในการอัปเดตไฟล์ CSV ที่เผยแพร่)

## ข้อจำกัดที่ควรทราบ

- ถ้ายังไม่ได้ตั้งค่า `API_URL` ข้อมูลการจองจะอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น เปิดจากเครื่อง/เบราว์เซอร์อื่นจะไม่เห็นข้อมูลเดียวกัน — ตั้งค่า `API_URL` ตามขั้นตอนด้านบนเพื่อให้ข้อมูลซิงก์กับทุกคนผ่าน Google Sheet
- Google Apps Script Web App มีลิมิตการเรียกใช้งาน (quota) ของบัญชี Google ส่วนตัว — เหมาะกับทีมงานขนาดเล็ก-กลาง
- การตรวจสอบเวลาจองซ้อนเป็นการตรวจที่ฝั่งเว็บ (client-side) หากมีคนกดบันทึกพร้อมกันเป๊ะๆ ในเสี้ยววินาทีเดียวกัน อาจมีโอกาสจองซ้อนหลุดได้เล็กน้อย — แนะนำให้เจ้าหน้าที่ตรวจสอบสถานะ "รอยืนยัน" ก่อนยืนยันจริงเสมอ
- Sheet ที่ Publish to web เป็น CSV (สำหรับรายชื่อโรงเรียนอ้างอิง) จะเป็นข้อมูลสาธารณะ (ใครมีลิงก์ก็ดูได้) — ควรใส่แค่ข้อมูลอ้างอิงทั่วไป ไม่ควรใส่ข้อมูลอ่อนไหว
- ไฟล์ Word ที่ดาวน์โหลดเป็นไฟล์ `.docx` จริง (สร้างด้วยไลบรารี docx.js) แสดงผลฟอนต์ TH Sarabun PSK ได้สวยงามตรงแบบเมื่อเครื่องที่เปิดไฟล์มีฟอนต์นี้ติดตั้งอยู่
